# LaunchAgent Automation

## Purpose
Run memory snapshot automatically every 30 minutes on macOS.

## Install
```bash
zsh /Users/pabloagent/.openclaw/workspace/tools/install_memory_launchagent.sh
```

## Uninstall
```bash
zsh /Users/pabloagent/.openclaw/workspace/tools/uninstall_memory_launchagent.sh
```

## Logs
- `/tmp/com.pabloai.memory-snapshot.out`
- `/tmp/com.pabloai.memory-snapshot.err`
