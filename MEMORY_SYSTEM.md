# MEMORY_SYSTEM.md

## Purpose
Este workspace mantiene memoria persistente para continuidad real a largo plazo.

## Core files
- `MEMORY.md` — memoria larga curada
- `memory/preferences.md` — preferencias de Pablo
- `memory/decisions.md` — decisiones importantes
- `memory/YYYY-MM-DD.md` o `memory/daily/YYYY-MM-DD.md` — bitácora diaria
- `memory/projects/*.md` — proyectos
- `memory/timeline/YYYY/MM.md` — línea de tiempo
- `memory/system/*.md` — reglas y arquitectura

## Rules
- Escribir lo importante; no depender de memoria implícita.
- Hacer checkpoints en tareas largas.
- Consultar memoria antes de responder sobre contexto pasado.
- Consolidar periódicamente a memoria larga.

## Priority
Conclusiones primero. Respuestas cortas y directas.
