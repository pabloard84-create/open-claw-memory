# BACKUP_PLAN.md

## Goal
Make memory durable over years.

## Recommended layers
1. Git versioning for all memory files.
2. Remote private backup (private repo or synced folder).
3. Periodic snapshot/export.

## Minimum
- Configure git identity.
- Commit memory changes regularly.

## Better
- Push to a private remote.
- Keep local machine backups active.

## Rule
Uncommitted memory is fragile memory.
